# Douceur — Une Douceur Inégalée

Une plateforme élégante pour la marque **Douceur**, spécialisée dans les produits d'hygiène et de confort premium.

## 🚀 Caractéristiques
- **Design Premium** : Interface moderne, responsive et fluide.
- **Showcase de Produits** : Présentation détaillée des gammes (Douceur 4D, Industriel, etc.).
- **Formulaire de Contact Intelligent** : Intégration directe avec Google Apps Script pour un suivi efficace.
- **Optimisation SEO** : Structure sémantique et balises META optimisées.

## 🛠️ Technologies
- **Frontend** : HTML5, CSS3 (Vanilla), JavaScript (ES6+).
- **Backend** : Google Apps Script (pour le traitement des formulaires).
- **Polices** : Google Fonts (Satisfy, Nunito).

## 📦 Installation & Déploiement

### Local
Pour lancer le projet localement :
1. Clonez le dépôt.
2. Ouvrez `index.html` dans votre navigateur ou utilisez un serveur local (ex: Live Server).

### Configuration du Formulaire
Consultez le fichier [INSTRUCTIONS-FORMULAIRE.md](INSTRUCTIONS-FORMULAIRE.md) pour connecter le formulaire de contact à votre adresse email via Google Apps Script.
